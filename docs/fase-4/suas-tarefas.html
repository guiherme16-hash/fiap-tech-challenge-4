FAÇA AGORA — 2 contas grátis ~20 min

Crie as duas e guarde os 2 segredos num bloco de notas. A gente injeta no cluster no domingo.

APM/Tracing mudou (boa notícia): o professor liberou cobrir o APM com a stack Grafana open-source, então NÃO precisa de New Relic. Os traces vão pro Grafana Tempo, que roda dentro do próprio cluster — sem conta externa, sem chave. Uma preocupação a menos. Sobraram só 2 contas:

1) PagerDuty Incidente

  • Entre em https://www.pagerduty.com/sign-up/ e crie a conta (trial/free).
  • Menu Services → New Service → nome togglemaster.
  • Na etapa de integração, escolha Events API V2 e finalize.
  • Abra o serviço criado → aba Integrations → COPIE a Integration Key (32 caracteres).

2) Discord ChatOps / Aviso

  • Num servidor seu (ou crie um grátis em https://discord.com/): Configurações do Servidor → Integrações → Webhooks.
  • Novo Webhook → escolha o canal (ex.: #alertas) → COPIE a URL do Webhook.
Regra de ouro dos segredos: NÃO cole as 2 chaves aqui no chat e NÃO faça commit delas no git. Guarde num bloco de notas local. No domingo a gente injeta tudo via Secret do Kubernetes (fora do git), do mesmo jeito que já é feito com as senhas de banco.

Pra o domingo — deixe pronto

  • Login AWS: use o profile fiap (credenciais na pasta .aws). Confirme que aws sso login --profile fiap funciona e que kubectl/terraform enxergam a conta.
  • Repositório da Fase 4: me diga a URL do repo no GitHub onde a Fase 4 vai morar (os manifests do ArgoCD ainda apontam pro repo da Fase 3). Com a URL eu faço um ajuste único em tudo.
  • GitHub: confirme que você consegue adicionar Secrets no repo (Settings → Secrets and variables → Actions). É o que o self-healing vai usar.
Custo AWS: EKS + load balancers + bancos custam por hora. A gente sobe só no domingo pra testar/gravar e dá terraform destroy depois. Não deixe o cluster no ar de um dia pro outro.

Cola rápida (pro vídeo)

Os conceitos em 1 frase, pra você narrar sem travar:

  • Métricas (Prometheus): os sinais vitais — CPU, memória, nº de requisições. Como o painel do carro.
  • Logs (Loki): o diário detalhado do que cada serviço registrou. Onde se acha o erro.
  • Traces (Grafana Tempo / APM): o caminho de UMA requisição passando por vários serviços. Como rastrear uma encomenda.
  • OTel Collector: o correio central que recebe tudo dos serviços e distribui pra ferramenta certa. Peça obrigatória.
  • Grafana: a "TV" com os painéis.
  • Alerta → PagerDuty → Discord: o alarme que abre incidente e avisa a equipe.
  • Self-Healing: o piloto automático que reinicia o serviço sozinho antes de incomodar alguém.
